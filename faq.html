Authoritative CCoE Glossary

Speak the Same Language

TermDefinition
AOAuthorizing Official — the senior official with authority to formally accept risk and authorize system operation.
AODRAO Designated Representative — performs authorization review and coordination on the AO's behalf; recommends but does not accept risk.
ACASAssured Compliance Assessment Solution — the DoD enterprise vulnerability scanning capability (Tenable-based).
ATCAuthorization to Connect — permission for a system to connect to a network, distinct from authority to operate the system itself.
ATO-CConditional ATO — authorization granted with binding conditions (typically POA&M milestones) whose breach can trigger revocation.
CCIControl Correlation Identifier — decomposes NIST controls into single, assessable statements used in STIGs and eMASS.
CUIControlled Unclassified Information — unclassified information requiring safeguarding under law, regulation, or government-wide policy.
FedRAMPFederal Risk and Authorization Management Program — standardized federal approach to cloud service security authorization.
IATTInterim Authorization to Test — short-duration authorization for testing in an operational environment, with explicit boundaries and restrictions.
ILImpact Level — DoD cloud data sensitivity tiers (IL2 public ↔ IL6 classified) governing where workloads may reside.
ISSMInformation System Security Manager — manages cybersecurity for assigned systems/programs; the ISSO's governance chain.
ISSOInformation System Security Officer — executes daily security operations, evidence collection, and POA&M hygiene for assigned systems.
POA&MPlan of Action and Milestones — the managed record of a weakness, its remediation plan, resources, and milestone dates.
RAWRisk Assessment Worksheet — structured analysis translating findings into risk statements supporting the authorization decision.
RMFRisk Management Framework — the NIST 7-step lifecycle (Prepare → Monitor) governing system authorization.
SARSecurity Assessment Report — the assessor's findings on control effectiveness, feeding the RAW and AO decision.
SCASecurity Control Assessor — independently validates control implementation and produces the SAR.
SCA-RSCA Representative — performs assessment activities under SCA authority and direction.
SSPSystem Security Plan — the authoritative description of the system boundary, environment, and control implementation.
STIGSecurity Technical Implementation Guide — DISA-published configuration standard for securing specific technologies.

Missing a term? Tell the Knowledge Manager — additions ship weekly. For the source documents themselves, see the References & Authorities Library.
