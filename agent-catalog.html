How Access Works

Requesting Agent Access

Every agent in this catalog is approved for use within defined guardrails. Access is granted by the agent owner — not centrally provisioned — so they can brief you on scope, limitations, and data handling requirements.

1

Find an Agent

Search or filter the catalog above. Review the description, capabilities, and category to find the agent that matches your use case.

2

Contact the Owner

Click "Request Access" to email the agent owner directly. Include your name, role, and the system or use case you need the agent for.

3

Get Briefed & Approved

The owner briefs you on guardrails, data handling, and limitations. Once approved, you receive access credentials and documentation. You own every output.

AccountabilityUsing an AI agent does not transfer ownership of its output. If your signature block is on it, you reviewed it line by line. No CUI or system-identifying data into any agent outside an approved, key-backed deployment. See the AI & Automation Center for full guardrails.
